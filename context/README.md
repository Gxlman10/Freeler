# Contexto del Proyecto Freeler

Esta carpeta es la memoria viva del proyecto.

## Estructura

- `estado-actual.md`: arquitectura actual, reglas de negocio implementadas y resumen del esquema de BD.
- `plan-detallado.md`: decisiones ya aprobadas en fase de implementacion (con tareas concretas).
- `ideas.md`: iniciativas en fase de exploracion, aun sin compromiso de ejecucion.

## Regla de actualizacion

Cuando cambie codigo relevante de frontend o backend, registrar primero el cambio aqui y luego commitear.
